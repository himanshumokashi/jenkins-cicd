# Portfolio Website

My personal portfolio website built using HTML, CSS, and JavaScript and deployed using DevOps tools.

## Technologies Used

- HTML, CSS, JavaScript
- Git and GitHub
- Linux (Ubuntu)
- Docker
- Jenkins
- AWS EC2
- Nginx

## Project Features

- Responsive portfolio website
- Docker containerization
- Jenkins CI/CD pipeline
- Automated deployment to AWS EC2

## Run Locally

```bash
git clone https://github.com/himanshumokashi/portfolio-website.git
cd portfolio-website
docker build -t portfolio-website .
docker run -d -p 8080:80 portfolio-website
```

Open `http://localhost:8080` in your browser.
